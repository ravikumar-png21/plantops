# Terminal and Git cheat sheet

| Command | What it does |
|---|---|
| `pwd` | show the folder I am in |
| `ls` | list files here |
| `cd name` | go into a folder |
| `cd ..` | go up one level |
| `cd ~` | go to home folder |
| `mkdir name` | make a folder |
| `touch file` | make an empty file |
| `cat file` | print a file |
| `open .` | open this folder in Finder |
| `open -e file` | open a file in TextEdit |
| `git status` | show what changed |
| `git add -A` | put all changes in the staging area |
| `git commit -m "msg"` | save a commit with a message |
| `git push` | upload commits to GitHub |
| `git log --oneline` | list commits, newest first |
| `git checkout name` | switch to a branch |
| `git checkout -b name` | create and switch to a new branch |
